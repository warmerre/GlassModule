# Liquid Glass Icons (LSPosed)
Сборка: Android Studio -> Build APK, или `./gradlew assembleDebug` (нужен gradle wrapper).
Установка: поставить APK -> LSPosed -> включить модуль -> scope: лаунчер -> перезапустить лаунчер.
Лаунчеры: Launcher3 (LineageOS Trebuchet) и Pixel Launcher (PixelOS). Android 12+.
